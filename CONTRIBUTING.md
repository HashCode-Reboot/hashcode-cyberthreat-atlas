# Contribuer à CyberThreat Atlas

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Les données doivent avoir une provenance, une date et un niveau de confiance. Filtrer les données sensibles avant publication. L'objectif est la défense et la recherche responsable.

Une PR doit expliquer la source, la transformation, la validation et les limites.
