# Roadmap V0.1

Foundation: define threat-intelligence sources, taxonomy, provenance and confidence.

Architecture: define normalized threat objects, source connectors, storage and exploration boundaries.

MVP: deliver ingestion → normalization → indexing → exploration of representative threats.

Validation: verify provenance, deduplication, search quality and source reliability.

Release: complete security, data-quality, documentation, limitations and reproducibility checks before V0.1.
